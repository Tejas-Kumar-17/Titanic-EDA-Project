#  Titanic Survival Analysis & EDA Project

##  Internship Project
This project was completed as part of the **Data Science with Python Internship**.

We analyzed the famous Titanic dataset to understand survival patterns using Python and data visualization techniques.

---

##  Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

---

## Files Included
| File | Description |

| titanic.csv | Titanic dataset |
| Task2 Notebook | Basic analysis & visualizations |
| Task3 Notebook | Mini EDA with advanced insights |

---

##  Task 2 Work
- Data cleaning
- Survival by gender
- Survival by class
- Age distribution
- Bar charts

---

##  Task 3 Work (Mini EDA)
- Mean imputation for Age
- Cabin column removed
- Feature engineering (Family Size, Age Group)
- Survival by Age Group
- Survival by Embarkation Port
- Survival by Family Size
- Correlation heatmap
- Multiple visualizations

---

##  Key Insights
- Females survived more than males
- First-class passengers had higher survival
- Children had better chances
- Small families survived more
